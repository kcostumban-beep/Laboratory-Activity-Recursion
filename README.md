# Laboratory Activity: Recursion

## Brief Description

This program demonstrates the use of recursion in Java. 
It uses a recursive binary search algorithm to find a specific value in a sorted array.

## Programming Language Used

Java

## Instructions for Compiling and Running

1. Download or clone this repository.
2. Open the Java source file in a Java IDE such as JCreator, NetBeans, IntelliJ IDEA, or another Java compiler.
3. Compile the program.
4. Run the program.
5. Enter the required input when prompted.

## Sample Input

Enter the number to search: 25

## Sample Output

Element 25 found at index 2.
